# Languages

Read when changing known languages, learned choices, language reminders, or their persistence.

- `CharacterSheet` owns `Languages`. The typed `languages.spoken` collection accepts `LanguageGrant {id, source, languageId}`. These grants cost no learning choices and are removed by grant ID. Multiple sources may grant the same language; the View deduplicates it, and one source's removal leaves other grants intact.
- `Languages::add(languageId, origin)` learns a language using `Intelligence` or `Linguistics`. Blank IDs, duplicate known languages, invalid origins, exhausted quotas, and disallowed choices are rejected. `remove(languageId)` removes only a learned choice and refunds its origin; it cannot withdraw external grants. A later grant overlapping a learned language does not silently refund or erase the learned choice.
- Linguistics capacity reads actual invested ranks, not the skill total. Intelligence capacity is now calculated live as `max(0, intPermanentMod)`, excluding temporary modifier contributions. The independent entitlement field and both setters have been removed. Standalone owners must register the permanent Intelligence target before querying quotas/reminders. Persistent score changes affect choices immediately; decreases preserve learned selections and report excess instead of deleting languages.
- The typed `languages.options` collection accepts `LanguageOptionsGrant {id, source, origin, languageIds}`. Sources contribute additive allowlists separately for Intelligence and Linguistics. No registered list (or only empty lists) permits no new learned choices. `add` requires membership in the origin's union; the optional read-only `isAllowed(languageId, origin)` callback can further restrict it. Blank/duplicate normalized IDs and invalid origins reject. Adding/removing a source refreshes reminders without deleting existing selections. No language catalog or automatic racial/secret-language policies are installed; providers must register the appropriate lists. IDs remain catalog strings.
- `refreshReminders()` publishes separate Italian reminders for remaining Intelligence/Linguistics choices, choices exceeding a reduced quota, and selections rejected by a changed filter. Learned languages are preserved when quotas or filters change. Sheet rank changes and View generation refresh reminders; standalone users must refresh after changing callback state.
- `LanguagesView` contains deduplicated spoken IDs, granting sources, optional learned origin, remaining quotas, and sorted/deduplicated allowed options grouped by origin. Options reflect the extra callback filter but do not remove known languages or depend on remaining quota; `add` still checks both. An absent origin in options means no allowed choices. `LanguagesData` saves only learned language IDs/origins, never quotas, grants, callbacks, or calculated reminders. Format 35 removes `intelligenceBonus` from new saves. A legacy field, when present, is validated and discarded: the restored permanent score determines entitlement, preserving all selections even if the old manual quota differed. Pre-26 saves have no learned choices; both quotas are derived from restored sheet state. Load validates structure and preserves selections even if current quotas/filter no longer allow them, reporting discrepancies instead of deleting data.
- `LanguageOptionsEffectDefinition` is parsed as `{"id":"bonusLanguages","type":"languageOptions","origin":"intelligence","languageIds":["draconic","orc"]}`; origin is the closed Intelligence/Linguistics enum. The compiler registers a source-owned list and returns cleanup. Empty arrays are valid empty contributions; malformed arrays, unknown origins and duplicate/blank IDs reject. Lists are reconstructed from effects rather than saved in LanguagesData; source lists themselves require no persistence fields.
- `LanguageGrantEffectDefinition` is parsed as `{"id":"...","type":"languageGrant","languageId":"..."}`. `compileEffect` uses the owning effect's stable instance ID/source and returns exact grant cleanup. The current race catalog still uses language reminders; replacing them and connecting bonus lists are separate next steps. No frontend or C API additions were made.

Rules references: [Intelligenza](https://golarion.altervista.org/wiki/Intelligenza), [Linguistica](https://golarion.altervista.org/wiki/Linguistica), and the race language lists such as [Elfo](https://golarion.altervista.org/wiki/Elfo). English skill terminology follows Golarion's linked [Linguistics](https://www.d20pfsrd.com/skills/linguistics).
