# Playable Class Catalog

Read when changing embedded class data or reviewing its automation boundaries. Runtime ownership is documented in [classes.md](classes.md).

## Scope and Sources

- The default manager embeds 44 playable Golarion classes: 11 core, 10 advanced, 3 alternative, 10 hybrid, 6 occult and 4 unchained. Prestige and NPC classes are excluded. Archetypes now have a separate [partial catalog](archetype-catalog.md).
- Runtime files live in `core/sheet/resources/classes/`; `catalog.sources.json` records the 44 Golarion source pages and is not runtime input. Rules were collected only from Golarion.
- All definitions contain hit dice, base skill ranks, typed class skills and 20 numerical rows (880 total). Rows store total BAB and base saves. There are 762 feature records, including source-linked privilege reminders, a dedicated sorcerer bloodline-selection owner and explicit metadata compatibility identities needed by archetypes.
- Unimplemented rule portions end with `Ehi, appena hai tempo vedi di correggermi se necessario!`. Catalog presence does not imply complete class automation.

## Implemented Mechanics

- 25 classes grant independent prepared, spontaneous or flexible casting instances, with source-owned daily slots and known/prepared quotas from their Golarion tables. Alchemist and Investigator extracts remain manual, not counterfeit spellcasting.
- Stable casting grants use acquisition `spellcasting` and effect `casting`. Dependent grants use the runtime ID generated by `CharacterClass::effectKey`; changing these IDs requires updating dependent effects. Casting features are ordered before their consumers.
- Level-specific slot upgrades replace previous slot acquisitions, not the casting owner. Repertoire quota increments retain stable acquisition IDs so earlier selections survive advancement. Arcanist preparation and casting capacities remain separate.
- 48 supported static/conditional feature overlays cover selected bonus feats, skill/save/AC bonuses, movement, damage reduction, Dexterity retention and immunities. Remaining parts of these privileges retain marked reminders.
- Three additional language features register Druid/Shifter Druidic grants and their Intelligence-language options, plus Cleric bonus languages. Secret-language restrictions remain descriptive; Druidic is not added to the global Linguistics list.

## Explicit Boundaries

- Source review covers option families of all 44 playable classes; supported finite selections are attached through the [option loader](class-options.md), using existing Data/View and pending-choice reporting. Eligibility, repeated-selection limits, new benefits and unsupported dependent/point-budget/creature families remain explicitly manual; list presence is not complete automation.
- Ability-dependent bonus slots, initial Intelligence-dependent book entries and freely distributed book additions remain manual. Ability minima, caster level/DC, focus/book/familiar restrictions and activation timing are not newly enforced.
- Cantrip/orison reuse remains manual; a broad consumption exemption would incorrectly exempt higher-slot metamagic versions. No artificial unlimited level-zero casting slot is inserted.
- Restricted domain/school/spirit slots are not granted as unrestricted base slots. Extracts need their own supported semantics before automation.
- Alignment eligibility, equipment proficiency and contextual combat/action resolution remain manual where marked. The separate archetype dataset now supplies 661 definitions, with documented manual portions and 103 pending source entries.

## Loading and Verification

- Archetype integration adds metadata-only compatibility identities for class skills, selected BAB/rank/save changes and the Wizard spellbook, without changing the original grants. Missing standalone Druid spontaneous casting and Kineticist wild-talent rules now have real source-linked manual features. Medium's mislabeled Spirit feature and split Spirit Surge progression were corrected from its Golarion body text; original acquisition IDs are retained where possible. See [archetype coverage](archetype-catalog.md).

- `classDefinitionFromJson` / `classDefinitionToJson` provide a strict enum boundary and nested feature/choice/effect round trips. Unknown categories, malformed numbers, duplicate IDs, missing replacements and replacement cycles are rejected.
- `ClassDefinitionManager::instance()` parses the embedded catalog once. Explicit typed managers remain supported; archetype content is still independently supplied.
- `class_catalog_test` exercises every class from level 0 through 20 and back, numerical contributions, cleanup, reconstruction, multiclass casting separation and preservation of wizard repertoire quota IDs. `class_definition_json_test` covers malformed definitions and nested round trips. No play-module tests are required for this change.
- Verification on 2026-11-13: the sheet build succeeds and all 102 sheet tests pass, including expanded option selection/save-load/reactivation, archetype catalog lifecycle and numerical/continuity checks. The catalog audit confirms 44 unique classes, 880 ordered level rows and 44 matching source entries; option coverage is detailed in [class options](class-options.md). Save format and library version are unchanged.
